# مسار الدروس المفتوح — الإصدار 0.6

جميع الدروس الـ13 متاحة من البداية. اختر أي درس أو تمرين بأي ترتيب؛ لا توجد نقاط أو شروط اجتياز أو قفل للمستويات. المستويات الستة مجرد تنظيم للموضوعات: الأساسيات، الصلاحيات، XSS، CSRF/CORS، الوجهات وطلبات الخادم، والمعلومات المنشورة.

كل درس يتضمن شرحاً موسعاً، تدريباً يدوياً مع تلميحات، تفسير الإصلاح وحدوده، وتمريناً اختبارياً مستقلاً. افتح أي بطاقة، اقرأ «افهم السيناريو»، ثم جرّب التدريب. من «افهم الإصلاح» يمكنك بدء التمرين الاختباري دون الحاجة لإكمال درس آخر.

التدريب يستخدم بيانات إرشادية، والتمرين المستقل يبدأ جولة جديدة وقد يستخدم بيانات مختلفة: حساب Bob والبريد visitor@example.test، أو فاتورتي 2001 و2002، أو إشارة BB-EXAM في XSS. هذه البيانات ليست أسراراً؛ الهدف تطبيق الفكرة وجمع دليل فعلي. التلميحات تظهر في التدريب فقط، ويمكن العودة إليه في أي وقت.

قائمة المهمة تتحقق من ردود المختبر والأثر المطلوب. عند إكمالها تظهر علامة إنجاز اختيارية؛ لا تمنح درجة ولا تتحكم بالوصول لأي محتوى. يمكنك تكرار التمارين والتنقل حتى لو لم تكملها. دفتر الدليل يسجل نوع الجولة ومدخلاتك الوهمية ونتائجها، ويمكن تنزيله JSON.

علامات الإنجاز محفوظة محلياً في نفس المتصفح. الإنجازات السابقة تُقرأ كعلامات فقط. زر «مسح علامات الإنجاز» يمسحها بعد التأكيد، وتبقى كل الدروس مفتوحة. هذا ليس نظام شهادات أو امتحاناً محصناً ضد تعديل المستخدم.

بدء أي جولة يعيد ضبط حالة الخادم والبريد الوهمي والجلسة التعليمية؛ تجنب جولات متزامنة على نفس العملية. البيانات والأسرار وهمية، وحدود SSRF والتحويل والملفات موضحة في [دليل الدروس الإضافية](advanced.ar.md).

للتحقق كمطور:

```bash
python -m unittest discover -s tests -v
node tests/progression.test.cjs
```

اختبار المتصفح الاختياري `node tests/browser.cjs` يحتاج Playwright/Chromium وخادماً يعمل محلياً. يتحقق من فتح كل الدروس في متصفح جديد وبعد مسح العلامات، ومن التمارين الـ13 وعزل المتصفح وشكل الهاتف.
