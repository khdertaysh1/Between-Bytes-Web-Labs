# مسار المستويات والاختبارات العملية

## طريقة التعلّم

كل درس له أربعة أجزاء: شرح موسّع يحدد المفهوم وحدود الثقة، تدريب يدوي مع تلميحات، تفسير السبب والإصلاح، ثم اختبار عملي دون تلميحات. الاختبار يستخدم نفس مهارة الدرس في جولة جديدة، مع بيانات مختلفة عندما ينطبق ذلك؛ ليس مجرد سؤال اختيارات أو مشاهدة ديمو.

من بطاقة الدرس اقرأ «الشرح الموسّع»، ثم انتقل إلى التدريب. بعد فهم الإصلاح اضغط **ابدأ الاختبار العملي** في تبويب «افهم الإصلاح». هذا يبدأ جولة جديدة ويمسح عدّادات الخادم والبريد الوهمي. شريط الجولة يوضح هل أنت في تدريب أم اختبار.

## المستويات والنقاط

| المستوى | الدروس | شرط الفتح |
|---|---|---|
| 1 — أساسيات الحسابات والحدود | كشف الحسابات، Rate Limit، بريد الاستعادة | متاح منذ البداية |
| 2 — صلاحيات الموارد والطبقات | IDOR، edge/origin 403 | اجتياز اختبارات المستوى الأول الثلاثة: 300 نقطة |
| 3 — حقن JavaScript وسياقات العرض | Reflected XSS، DOM XSS | اجتياز جميع اختبارات المستويين الأول والثاني: 500 نقطة |
| 4 — الطلبات والأصول | CSRF، CORS | جميع اختبارات أول ثلاثة مستويات: 700 نقطة |
| 5 — الوجهات وطلبات الخادم | Open Redirect، SSRF | جميع اختبارات أول أربعة مستويات: 900 نقطة |
| 6 — المعلومات والأسرار | API Keys، ENV والنسخ الاحتياطية | جميع اختبارات أول خمسة مستويات: 1100 نقطة |

كل اختبار يُمنح **100 نقطة مرة واحدة** عند جمع أدلة المهمة المطلوبة للنسختين. المجموع الأقصى 1300 نقطة. لا توجد نقاط على القراءة أو التدريب أو المقارنة التلقائية، ولا تضاعف إعادة اختبار مجتاز الرصيد. المحاولات غير المكتملة لا تمنح نقاطاً ولا تخصمها؛ يمكن بدء الجولة من جديد للتعلّم.

المستوى التالي يعتمد على اجتياز جميع اختبارات المستويات السابقة، وليس رصيداً يجمعه تكرار درس واحد. الدخول برابط مباشر لدرس مقفل يعيدك إلى الصفحة الرئيسية مع تفسير شرط الفتح.

## بيانات الاختبار

- الحساب الموجود في اختبارات الأساسيات: `bob@example.test`، وغير الموجود في اختبار enumeration: `visitor@example.test`.
- في اختبار IDOR يبقى المستخدم Alice، لكن فاتورته `2001` وفاتورة Bob الوهمية `2002`. مطلوب السماح بفاتورة Alice ورفض فاتورة Bob في المُصلحة، مع إثبات قراءة فاتورة Bob في الضعيفة.
- في اختبارات XSS، إشارة التنفيذ المطلوبة `alert('BB-EXAM')`، وليست علامة التدريب `BB-LAB`. يلزم إعادة **نفس المدخل** في المُصلحة ورصده كنص دون إشارة تنفيذ خلال نافذة المعاينة. هذه النافذة المحدودة لا تنفي حمولة مؤجلة أو سياقاً آخر.
- اختبار 403 يستخدم فرعي edge وorigin المحليين في النسختين. لا يتصل بمنتج خارجي، وليس تجاوزاً لـCloudflare.

لا يحتوي الاختبار تلميحات أو مقارنة تلقائية. تستطيع العودة للتدريب من قسم الاختبار، لكن ذلك يبدأ جولة تدريب جديدة. دفتر الدليل يصدّر نوع الجولة والأدلة والنقاط المحفوظة للدرس. العلامات والبيانات المختلفة ليست أسراراً؛ الهدف تطبيق المهارة، وليس منع الطالب من رؤية المصدر المفتوح.

## كيف يتحقق النجاح؟

التقييم يعتمد على شروط واضحة من ردود المختبر: هوية الحساب والرمز والرد، مالك الفاتورة والمورد، عدد الرسائل، أو إشارة تنفيذ الإطار ونصه. لا نمنح نقاطاً لمجرد الضغط على «إرسال» أو ذكر اسم الثغرة. في XSS لا يكفي ظهور HTML منسق؛ يلزم رصد العلامة الصحيحة ثم عرض نفس المدخل كنص في المُصلحة.

## الحفظ وحدود نظام التقييم

النقاط محفوظة في localStorage على نفس المتصفح والجهاز. تبقى بعد تحديث الصفحة، لكن مسح بيانات الموقع أو تغيير المتصفح يفقدها. زر مسح التقدّم يصفّر التدريب والنقاط ويعيد قفل المستويات بعد تأكيد المسح. نتائج الإصدار 0.3 تُقرأ كتقدّم تدريب فقط ولا تتحول آلياً إلى نقاط اختبارات.

هذه بوابة تعلّم محلية يمكن لصاحب الجهاز تعديلها من أدوات المطور أو المصدر، وليست امتحاناً محصناً أو نظام شهادات أو ترتيباً تنافسياً. لا توجد مصادقة أو مزامنة حسابات أو حماية من تعديل الدرجات. العدّادات والبريد مشتركة بين تبويبات الخادم الواحد؛ تجنب تشغيل جولات متزامنة كي لا تتداخل الأدلة.

## التحقق للمطور

```bash
python -m unittest discover -s tests -v
node tests/progression.test.cjs
```

الأول لا يتطلب مكتبات خارجية، والثاني يفحص قواعد النقاط وفتح المستويات وحفظ الحالة دون إطار اختبارات إضافي. اختبار المتصفح الاختياري `node tests/browser.cjs` يحتاج Playwright وChromium وخادماً محلياً يعمل مسبقاً. يغطي التدريب دون نقاط، الاختبارات الثلاثة عشر، فتح المستويات عند 300 و500 و700 و900 و1100، عدم تكرار النقاط، الحفظ بعد التحديث، عزل XSS وشكل الهاتف.

دروس الإصدار 0.5 وحدود التجارب موثقة في [الدليل المتقدم](advanced.ar.md). نقاط الإصدار 0.4 محفوظة دون إعادة الاختبارات السابقة.
