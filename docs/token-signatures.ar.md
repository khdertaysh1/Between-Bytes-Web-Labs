# تمرين توقيع الرمز · 0.12.2

افتح أخطاء برمجية ثم «فك ترميز الرمز دون التحقق من توقيعه». ابدأ بالطلب السليم في
المُصلحة: 200 ودور viewer. الرمز ثلاثة أجزاء مفصولة بنقطتين؛ فك ترميز الجزء الأوسط،
وغيّر role إلى admin وأعد ترميز الحمولة دون إعادة توقيعها. أرسل الرمز المعدّل للضعيفة
ثم المُصلحة. افحص effective_role وadmin_panel وsignature_verified. المُصلحة تعيد 401
ولا تمنح صلاحية عند التوقيع غير الصحيح. مقارنة النتائج وحدها لا تمنح إنجازاً؛ يجب تنفيذ
الطلبات المطابقة والضابط السليم. التلميحات تظهر تدريجياً بزر التلميح.

Base64url ليس تشفيراً ولا إثبات هوية. عند استخدام أداة Base64 العامة بدّل - إلى + و_
إلى / وأكمل padding للفك، واعكس التحويل واحذف padding عند بناء جزء الرمز. يمكن أيضاً
استخدام Python المحلي لفك الحمولة وإعادة ترميزها. البيانات كلها وهمية؛ HMAC-SHA256
حساب فعلي داخل الخادم، لكن المفتاح معلن والساعة ثابتة عند 2000000000 لأجل التعليم.
لا تستخدم هذا المفتاح أو المحلل التعليمي في نظام حقيقي. النسخة المُصلحة تقيّد الخوارزمية
وتتحقق من التوقيع والانتهاء قبل استعمال الدور؛ لا تغطي إدارة المفاتيح أو issuer/audience
أو إبطال الجلسات. في الإنتاج استخدم مكتبة موثوقة وعقد تحقق كامل ومفتاحاً سرياً.

المصدر الأولي: [RFC 8725، التحقق من الخوارزمية والتوقيع](https://www.rfc-editor.org/rfc/rfc8725.html)،
راجعناه في 2026-11-21. الكود والشرح أصليان بترخيص المشروع MIT دون نسخ نص المصدر.
