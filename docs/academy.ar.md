# أكاديمية السيناريوهات · الإصدار 0.8

50 حالة متقدمة إضافية إلى الغرف الأساسية الثلاث عشرة. كل الحالات مفتوحة، بدون نقاط أو متطلبات فتح. افتح `http://127.0.0.1:8000/academy` بعد `python app.py`.

## طريقة العمل

حمّل الطلب السليم وشغّله في النسخة المُصلحة أولاً. عدّل JSON لإظهار أثر في الضعيفة، ثم أعد نفس المدخل في المُصلحة. لحالات حدود المحاولات، استهلك ميزانية النسخة الضعيفة بطلب البداية قبل المثال الثاني. اضغط «جولة جديدة» لتصفير حالة السيناريو الحالي؛ لا يتم حذف إنجازك المحفوظ تلقائياً.

الفحوص تربط أثر الضعيفة ورفض المُصلحة ببصمة جسم الطلب نفسه، مع ضرورة عمل طلب سليم بعد الإصلاح. العلم من نموذج الخادم للتعلم فقط وليس اختباراً مانعاً للغش. دفتر الأدلة محفوظ في الصفحة الحالية ويمكن تنزيله؛ علامات الإنجاز والاستنتاجات في localStorage. تغيير اللغة يفرغ عرض الجولة الحالي ولا يمسح حالة الخادم.

## حدود التنفيذ

الدفع محلي وهمي بالكامل: وحدات نقدية صحيحة وسجلات مزود ثابتة؛ لا بوابة دفع أو بطاقة أو تحصيل أو استرداد حقيقي. حالة webhook تستخدم عينة قرار توقيع معلنة، وليست بروتوكول مزود أو توليد توقيع حقيقي. حالة gift توضح ترتيب قراءة قديم بشكل حتمي ولا تشغّل سباق شبكة فعلياً.

عناوين IP تسميات من نطاقات التوثيق فقط. لا يتم تغيير IP جهازك أو تشغيل بروكسي. الوقت في حالة النافذة حقل ساعة مختبرية مقيد إلى 0..120 ولا يمثل ثقة بوقت العميل في الإنتاج. حدود الحساب والمصدر يجب تصميمها حسب نموذج التهديد؛ المحرك هنا يركز على ميزانية الحساب لسيناريوهات التجاوز.

XSS ينفذ داخل iframe مع sandbox دون allow-same-origin وسياسة CSP تمنع الاتصالات والموارد الخارجية. alert يرسل إشارة للصفحة الأم مع توكن لكل معاينة. التنفيذ والتحقق من غياب الإشارة يعتمدان على المتصفح ضمن نافذة قصيرة؛ لا يعطي الخادم علم إثبات تنفيذ لهذه الحالات. المعاينة قد تعرض نصاً أو رابطاً ثابتاً بعد الإصلاح؛ لا يُنفذ انتقال خارجي تلقائي. حالة stored تحفظ تعليقاً في جلسة الخادم ثم يعرضه طلب GET منفصل. حالتا DOM تستخدمان location.hash ومعامل search فعليين في رابط المعاينة.

SQLi يستخدم SQLite حقيقية في الذاكرة بصفين وهميين. NoSQL وتقييم القالب وSSRF والتحويل أمثلة مغلقة توضح قراراً محدداً؛ لا eval ولا قاعدة NoSQL فعلية ولا DNS أو نقل خارجي أو قراءة ملفات المضيف. ليست كل حالات XSS ولا كل أخطاء الدفع مغطاة، والصعوبة ليست مقياس خطورة.

الجلسة مقيدة بمتصفح محلي، حدها 32 جلسة وتنتهي بعد 30 دقيقة خمول، وتبقى في الذاكرة حتى إعادة التشغيل. ليست عزلاً بحاويات أو نظام حسابات إنتاجي. افتح عبر 127.0.0.1 فقط.

## مقارنات الحمولات والترميز

تتضمن قائمة صيغ XSS ثلاث عينات لكل سياق (36 عينة)، بينها مقارنات سلبية؛ عدم تنفيذ عينة ليس دليلاً عاماً على الأمان. حالة URL تفحص قرار href فقط لأن الإطار المبهم لا يثبت تنفيذ javascript:. إحدى عشرة حالة أخرى تفحص إشارة تنفيذ فعلية في المتصفح.

### `xss-html`

الحمولة الأساسية: راقب التنفيذ في الضعيفة وقارن النص في المُصلحة.

```json
{
  "value": "<img src=x onerror=alert(\"BB\")>"
}
```

صيغة ثانية لنفس السياق: اختلاف الصيغة لا يلغي الحاجة إلى مطابقة السياق.

```json
{
  "value": "<svg onload=alert(\"BB\")>"
}
```

مقارنة سلبية أو ترميز لا يفك هنا: الترميز المئوي لا يفك تلقائياً عند إدراج HTML.

```json
{
  "value": "%3Cimg%20src=x%20onerror=alert(1)%3E"
}
```

### `xss-attr-double`

الحمولة الأساسية: راقب التنفيذ في الضعيفة وقارن النص في المُصلحة.

```json

}
```
