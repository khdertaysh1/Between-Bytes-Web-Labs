# مساحة العمل اليدوي · 0.11.0

الشكل والشرح وقائمة المختبرات محفوظة. أضيفت مساحة عمل داخل الحالات الـ72، ويمكنك الوصول إليها مباشرة من «ابدأ التطبيق العملي» أعلى الحالة. اختر النسخة الضعيفة أو المُصلحة من المساحة؛ الاختيار متزامن مع محرر JSON السابق.

## الحقول والطلبات

ابدأ بالتطبيق. كل حقل له قيمة ونوع، وخيار «إرسال الحقل». تستطيع حذف حقل، تغيير نوعه، أو كتابة مدخل جديد. مثلاً في NoSQL غيّر نوع password من string إلى json ثم اكتب كائن المقارنة بنفسك. يرسل زر التنفيذ طلباً فعلياً إلى محرك الحالة نفسه، ولا يصنع استجابة داخل الواجهة.

سجل الطلبات يلتقط طلبات POST التي ترسلها من محررات الحالة، مع الطريقة والنسخة والحالة والزمن والجسم. هذا ليس بديلاً كاملاً عن DevTools ولا يلتقط جميع موارد الصفحة. حدد طلباً واحداً لتحريره أو إعادته، أو طلبين للمقارنة الملونة. سجل المتصفح المرافق منفصل ويعرض الطلبات التي رصدها خادم التجربة فعلياً.

الإعادة تنفذ العملية مرة أخرى. قد تحذف مورداً، أو تستهلك ميزانية، أو تضيف معاملة. استخدم «جولة جديدة» عندما تحتاج بداية متطابقة. الطلب المرفوض يظهر بحالته الحقيقية، مثل 400 أو401 أو403 أو415 أو422 أو429، ولا يحصل على علامة نجاح لمجرد إرساله.

## محرر HTTP والترميز

يمكنك تعديل جسم الطلب، ونوع المحتوى، ورأس X-Forwarded-For في مختبر حدود المحاولات. المسار مقيد بالحالة الحالية وبنسختيها، وHost يبقى محلياً. Origin وCookie رؤوس يديرها المتصفح؛ لا يزوّر المحرر قيمتهما. قيمتهما داخل JSON في نماذج السياسة تظل مدخلات تدريبية فقط.

أدوات URL وHTML وBase64 تعرض الناتج قبل تطبيقه على حقل تختاره. Base64 يدعم النص العربي بترميز UTF-8؛ المدخل غير الصحيح يعرض خطأ واضحاً. لا تعني عملية الترميز وحدها نجاح حمولة.

## المتصفح والنتائج

- **XSS:** المعاينة تعمل فعلياً داخل إطار معزول. تبويب المتصفح يعرض لقطة من DOM الناتج ورسائل التنفيذ والأخطاء؛ راقب اختلاف النص عن البنية. حالة URL تفحص سياسة href فقط.
- **الدفع والصلاحيات والعدّاد:** اقرأ المورد والمعاملات أو هوية المالك أو المحاولات المقبولة والمحجوبة. النتائج تأتي من المحرك المحلي.
- **SSRF وOpen Redirect:** تتبع السياسة والخطوات والوجهة داخل النموذج المغلق. لا يوجد اتصال بالشبكة الخارجية أو تحويل إلى مواقع خارجية.

## كتابة صفحة CSRF بنفسك

1. افتح تبويب المتصفح ثم «تشغيل جلسات المتصفح».
2. يظهر حساب المستخدم المختبري. احفظ ملاحظة سليمة منه لتتعرف على الميزة. تستطيع عرض حساب الباحث أيضاً؛ حساباهما مستقلان.
3. اكتب HTML وJavaScript في المحرر أو حمّل مثالاً قابلاً للتحرير. عدّل الملاحظة أو الحقول أو الكود، ثم شغّل صفحتك.
4. نفّذ الإجراء داخل صفحتك وشاهد حالة الحساب وسجل الخادم. طلب no-cors لا يكشف استجابته للصفحة؛ لذلك يؤخذ رمز الحالة من سجل الخادم، ويؤخذ الأثر من بيانات الحساب.
5. اختر المُصلحة وحمّل مثال هذه النسخة أو اكتب عنوانها في صفحتك، ثم كرر المحاولة. اختبر أيضاً الحفظ السليم داخل الحساب.

الحالات الست تختبر غياب الرمز، والرمز الفارغ، ورمز جلسة أخرى، وإعفاء الأصل، وGET، وtext/plain. في تجربة إعفاء الأصل، الخطأ المحلي هو الثقة ببداية الأصل مع تجاهل المنفذ؛ مثال مطابقة اسم المضيف يبقى في نموذج JSON.

جولة المتصفح الجديدة تمسح بياناتها وتغيّر روابطها، وتبطل صفحات وروابط الجولة السابقة حتى لا تكتب طلبات متأخرة في الجولة الجديدة. يحتفظ المحرر بالكود؛ حدّث روابطه أو حمّل مثالاً جديداً قبل التشغيل. علامات نموذج JSON منفصلة عن تجربة المتصفح.

## تجربة CORS المرافقة

اكتب طلب fetch من الصفحة الثانية مع credentials: include إلى مورد الحساب التجريبي. في الضعيفة يمكن قراءة البيانات بسبب عكس الأصل. في المُصلحة يبقى طلب المورد 200 لكن المتصفح لا يسمح لصفحتك بقراءة الجسم. سجل الخادم يثبت وصول الطلب، وسجل المتصفح يبيّن القراءة أو المنع.

هذه التجربة تختبر عكس الأصل فقط. حالات null ومطابقة البداية والنهاية والبروتوكول والطلب التمهيدي موضحة في نموذج السياسة؛ لا تنسب نتيجة تجربة العكس إلى جميعها.

## الحدود والحفظ

كل الخدمات تعمل على loopback. لا توجد حسابات أو مدفوعات حقيقية. أصل الصفحة الثانية يختلف بالمنفذ لكنه من الموقع نفسه؛ هذا لا يثبت تجاوز SameSite. صفحات المتدرّب معزولة، وسياسة المحتوى تقيد fetch والنماذج والموارد إلى الخدمات المحلية المسموحة، ولا ترسل رسائلها إلى منصة التعلّم إلا من إطار الصفحة وأصلها ورمز تشغيلها الصحيحين.

مدخلات الحالة والنسخة والملاحظة غير المحفوظة تبقى عند تبديل اللغة. المسودات وسجل الأدوات في ذاكرة الصفحة؛ إعادة تحميل الصفحة لا تحفظهما بشكل دائم. اكتب الاستنتاج ثم احفظه أو نزّل الدليل قبل الإغلاق. المعاينات قيد التنفيذ تتوقف عند التنقل بين الحالات أو تغيير النسخة.
