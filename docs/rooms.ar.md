# الغرف المحلية بالعربي والإنكليزي — الإصدار 0.7

التطوير يشمل الغرف الـ13، وليس IDOR وحده. كل غرفة لها سياق تطبيق وهمي يناسب الموضوع: دعم واستعادة حساب، دخول، بريد، فواتير، إدارة، بحث، معاينة DOM، تفضيلات حساب، API، تحويلات، جلب روابط، حزمة واجهة وملفات نشر. الواجهة تشغّل معالجات المختبر المحلية؛ ليست آلات سحابية أو نسخة إنتاجية من منصة تدريب كبيرة.

## اللغة

زر اللغة أعلى الصفحة يبدّل الواجهة والشروحات والمهام والتلميحات وقوائم التحقق وتسميات النتائج. العربي RTL والإنكليزي LTR، والاختيار محفوظ على المتصفح. التبديل يعيد تحميل العرض؛ علامات الإنجاز تبقى، لكن دفتر جولة لم تنتهِ لا يُحفظ، لذلك ابدأ جولة جديدة بعد التبديل. قيم البروتوكول والبيانات التقنية تبقى بأسمائها الأصلية. لا نرسل المحتوى إلى خدمة ترجمة أو CDN.

## التطبيق ومحرر الطلبات

ابدأ التدريب ثم استخدم نموذج التطبيق واقرأ الاستجابة. لكل غرفة اسم خدمة وهمية وعنوان الأصل المحلي الحقيقي. محرر HTTP يبني الطلب من المدخلات، ويسمح بتعديل جسمه والترويسة المدعومة وإعادته إلى مسار الغرفة الحالية فقط. يرفض الوجهات الخارجية وتغيير Host أو Cookie أو Origin والحقول غير المدعومة أو المكررة.

تسع غرف تعتمد على معالجات HTTP ويمكن إعادة طلباتها من المحرر. غرف XSS وCSRF وCORS الأربع تحتاج سلوك متصفح؛ استخدم نموذج التطبيق فيها، والمحرر يعرض الدليل المرصود بدلاً من الادعاء أن طلب HTTP نصياً يثبت التنفيذ أو القراءة. كل الدروس والتمارين مفتوحة، ولا توجد نقاط أو شروط انتقال.

## حالة مستقلة لكل متصفح

عند بدء جولة تُنشأ جلسة تعليمية محلية بملف كوكي عشوائي HttpOnly. العدّادات والبريد وحالة الملاحظة وتوكن CSRF والسجل منفصلة بين المتصفحات ذات الكوكي المختلفة. تبويبات نفس ملف المتصفح تشترك بالحالة وقد تؤثر ببعضها.

الحد الأقصى 32 مساحة تدريب في الذاكرة، وتنتهي غير النشطة بعد 30 دقيقة. إعادة تشغيل الخادم تمسحها. هذا فصل لحالة التطبيق داخل عملية واحدة، وليس عزلاً بنظام تشغيل أو Docker أو خدمة حسابات إنتاجية. شغّلها على loopback كما هي.

## الأدلة والعلامات

الخادم يسجّل استجابات المعالجات الفعلية للغرفة الحالية في سجل محدود بـ120 حدثاً، دون تسجيل قيم كوكي الجلسة أو توكن CSRF. عند استيفاء شروط الغرف التي يمكن ملاحظتها من الخادم تظهر علامة `BB{...}` جديدة من حالة الخادم. بدء جولة جديدة يمسح السجل ويغير العلامة. العلامة تثبت شروط النموذج المحلي فقط، وليست مكافأة أو شهادة أو اختراق خدمة حقيقية.

غرف XSS وCORS موصوفة صراحة بأنها **تحتاج دليل المتصفح**: وصول طلب معاينة إلى الخادم لا يثبت تنفيذ JavaScript، وطلب قراءة لا يثبت أن JavaScript استطاعت قراءة الرد. لذلك تبقى قائمة أدلة المتصفح مطلوبة، ولا يعطي تقرير الخادم وحده علامة نجاح لها. قائمة الإنجاز المحلية ليست امتحاناً محصناً ضد تعديل المستخدم.

حدود المحاكاة السابقة ما زالت قائمة: SSRF نقل وهمي بلا اتصال، والتحويل معاينة قرار لا انتقال خارجي، وملفات ENV والمفاتيح عينات غير صالحة داخل الذاكرة. CSRF وCORS تجارب فعلية بأصلين محليين مختلفي المنفذ ضمن نفس الموقع.

## اختبارات التطوير

اختبارات Python وقواعد الوصول، وتجارب المتصفح الـ13 باللغتين، وفحص الترجمة الإنكليزية عبر تبويبات كل غرفة، وحفظ اللغة واتجاه الصفحة، ومحرر الطلبات وحدوده، وفصل جلستين، وحدود رصد الخادم، وعرض الهاتف. تفاصيل الأوامر والتصميم في [الدليل الإنكليزي](rooms.en.md). التشغيل العادي ما زال `python app.py` دون حاجة إلى Node أو أدوات التطوير.
