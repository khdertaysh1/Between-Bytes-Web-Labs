# مختبرات الموارد والهوية · 0.12.0

أضيفت أربع غرف مستقلة، لكل منها ست حالات. جميعها مفتوحة وتستخدم مساحة العمل الحالية: حقول قابلة للتعديل، محرر HTTP، سجل الطلبات، الإعادة، المقارنة والترميز. الشرح عربي وإنكليزي.

| الغرفة | الحالات |
|---|---|
| رفع الملفات | الامتداد النشط، الامتداد المزدوج، الثقة بنوع المحتوى، مسار اسم الملف، استبدال ملف مستخدم آخر، سياسة SVG النشط |
| Path Traversal | المسار النسبي، ترميز URL، فك الترميز مرتين، الشرطة العكسية، المسار المطلق، خداع بادئة المجلد |
| كشف المعلومات | ملف البيئة، بيانات Git، نسخة إعدادات احتياطية، فهرسة مجلد، تفاصيل خطأ، سر داخل إعدادات العميل |
| الاستعادة والجلسات | ربط الرمز بالحساب، إعادة استخدام الرمز، انتهاء الرمز، إبطال الجلسة، إكمال MFA، فصل أغراض الرموز |

## تجربة مقترحة

افتح غرفة ثم حالة. شغّل الطلب السليم على النسخة المُصلحة أولاً، ثم غيّر الحقل المذكور في الشرح وجرّب النسخة الضعيفة. أعد الطلب نفسه على المُصلحة؛ قارن رمز HTTP والجسم وأثر العملية، لا الرمز وحده. من تبويب الطلبات حدّد المحاولتين وافتح المقارنة. سجّل تفسيرك قبل فتح مثال الطلب المخالف.

في رفع الملفات تعرض `files` المحتوى والمالك، و`resolved_path` مسار التخزين الافتراضي، و`execution_performed=false` يوضح أن الملف لم يُنفذ. نجاح الرفع يعيد 201؛ مخالفة التنسيق تعيد 415، ومخالفة الملكية أو مسار التخزين تعيد 403. الحد 30 ملفاً للجولة؛ تجاوزه يعيد 409. أعد ضبط الحالة لبدء جولة نظيفة.

في Path Traversal تعرض `trace` النص الأصلي والمسار بعد الفك والتوحيد ثم نتيجة الاحتواء. الملف المفقود داخل المجلد يعيد 404؛ الخروج من المجلد يعيد 403 في المُصلحة.

كشف المعلومات لا يعني دوماً خطأ HTTP: إعدادات العميل تبقى متاحة بـ200 بعد إزالة `server_api_key`. ملف Git المكشوف لا يثبت استعادة كامل المصدر، وسجل الاستثناء لا يثبت SQL Injection. كل القيم التي تحمل DEMO غير صالحة لأي خدمة.

في الاستعادة تزداد مراجعة الحساب بعد نجاح التغيير ويُستهلك الرمز. إعادة رمز الاستعادة بعد نجاحه يجب أن تُرفض. جلسة الخروج أو المرحلة السابقة لـMFA معدّة مسبقاً في سجل الخادم؛ ليست حقول صلاحيات يمكن للمتدرّب تزويرها في المُصلحة.

## حدود التنفيذ

هذه خدمات افتراضية داخل ذاكرة خادم المختبر: لا تقرأ ملفات جهازك، لا تكتب خارج الخادم، ولا تنفذ ملفات مرفوعة أو ترسل بريداً أو تتصل بخدمات خارجية. مدخلات PNG:/HTML: تمثل تنسيقات تعليمية؛ ليست فاحص صور حقيقي. قبول SVG في النسخة الضعيفة يثبت سياسة تخزين غير آمنة فقط. مقتطفات الإصلاح تشرح المبدأ وليست مكتبة تعقيم إنتاجية جاهزة.

في تطبيق حقيقي يلزم محلل صور موثوق وإعادة ترميز، أو رفض SVG، مع تخزين معزول وأسماء مولدة وضبط الحجم والحصص. احتواء المسار يجب أن يراعي الروابط الرمزية ونظام الملفات وصلاحياته؛ النموذج الافتراضي لا يحاكي الروابط الرمزية. الرموز والجلسات هنا لها سجل اصطناعي؛ لا تحاكي توقيعاً تشفيرياً أو توصيل بريد.
